## Reproduce the analysis

The complete pipeline fits rolling HQR, HQR-W, and QRA models; calculates ACI, WACI, and DCP intervals; computes the reported metrics and bootstrap standard errors; runs the synthetic experiment and sigma sensitivity analysis; and generates the figures and tables described below.

The complete model fits, 1,000-replicate metric bootstrap, synthetic experiment, and 2,000-point sigma sweep take several hours on the machine used for the reported runs. This is an approximate end-to-end runtime; separate per-step timings have not been recorded. No GPU, cluster, or other special infrastructure is required.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then run the following from the repository root. `uv sync --locked` creates `.venv` and installs the exact dependency versions from `uv.lock`; `uv run --locked` runs the analysis in that environment:

```powershell
uv sync --locked
uv run --locked python scripts\run_paper.py
```

The project requires **Python 3.13** (`>=3.13,<3.14`). The direct runtime dependencies are pinned in `pyproject.toml`:

## Data

`data/df_2024.csv` is included in the repository and contains hourly electricity-price observations and three point forecasts. Its columns are `full_date`, `date`, `hour`, `real`, `pred1`, `pred2`, and `pred3`. The analysis derives the ensemble mean and standard deviation of the three forecasts from these columns.

The forecasts are private or generated by the author. No external data provider or separate data-use licence is specified for this file. The data is supplied here for reproducing the analysis; contact the package author for reuse or redistribution permissions.

## Synthetic experiment in the paper

The paper's synthetic experiment is a separate, fully simulated study; it does not use `data/df_2024.csv`. Its purpose is to compare the initial prediction intervals with ACI and WACI when the data-generating process switches between high- and low-uncertainty regimes. It illustrates the paper's central point: aggregate coverage alone can hide different performance across regimes, while WACI can adapt based on the similarity of initial interval widths.

The generator in `src/hqr_waci/simulation.py` creates 100 seeded runs, each with 10,000 observations and nominal miscoverage `alpha=0.2`. The series starts in the high-uncertainty regime (`sigma=7`) and switches between it and the low-uncertainty regime (`sigma=2`); the probability of a switch increases by 0.0001 at each time step and resets after a switch. The mean is fixed at 100. At each step, the code forms an initial interval using a deterministic, smoothly varying scale estimate around the active regime's standard deviation and a t critical value based on a sample size of 10. ACI and WACI use `gamma=0.01`; WACI uses `sigma=1`. The first 1,000 observations are used before test-period evaluation.

For each run, the experiment evaluates initial intervals, ACI, and WACI. The reported state-specific summaries average metrics across the 100 runs separately for high- and low-uncertainty observations and include the across-run standard deviations. The all-observation summary is also saved; it is useful for showing how pooling regimes can mask state-specific under- and over-coverage.

| Paper result | Included files | Generator |
| --- | --- | --- |
| High-uncertainty-state results | `results/synthetic_high_uncertainty_mean.csv`, `results/synthetic_high_uncertainty_std.csv` | `run_synthetic_experiments` in `src/hqr_waci/simulation.py`; saved by `run_paper` in `src/hqr_waci/paper.py` |
| Low-uncertainty-state results | `results/synthetic_low_uncertainty_mean.csv`, `results/synthetic_low_uncertainty_std.csv` | Same seeded 100-run experiment, summarized for the low-uncertainty observations |
| All-observation results | `results/synthetic_all_mean.csv`, `results/synthetic_all_std.csv` | Same seeded 100-run experiment, summarized across both regimes |
| Illustrative time-series example | `figures/synthetic_example_2.pdf` | The first seeded run; `plot_synthetic_intervals` in `src/hqr_waci/figures.py` plots the initial, ACI, WACI, and true intervals with the observations |

These are pre-generated outputs from the paper's synthetic analysis. Running `python scripts/run_paper.py` regenerates them along with the real-data analysis. The source generator is seeded and deterministic; the figure shows a selected segment of the first simulated run to make the regime change and interval adaptation visible.

## Intermediate datasets

The package includes the input data and the pre-generated intermediate datasets and results. The pipeline is:

1. `data/df_2024.csv` is the included hourly input. `scripts/run_paper.py` passes it to `src/hqr_waci/paper.py`, which loads it and derives the forecast-ensemble features.
2. `src/hqr_waci/paper.py` fits the models and conformal intervals for alpha 0.1 and 0.2. It writes `results/predictions_alpha_0.1.csv.gz` and `results/predictions_alpha_0.2.csv.gz`, the fitted test-period records used to calculate metrics.
3. The same module calculates point metrics and bootstrap samples. It writes `results/df_results_alpha_{alpha}.csv`, `results/df_{metric}_alpha_{alpha}.csv`, `results/df_standard_deviations_bootstrap_alpha_{alpha}.csv`, and the consolidated `results/paper_metrics.csv`.
4. The sigma sensitivity analysis writes `results/df_results_sigma_impact_alpha_0.2.csv`; `src/hqr_waci/figures.py` uses it and the alpha 0.2 point estimates to generate `figures/sigma_impact.pdf`.
5. The synthetic experiment described above writes `results/synthetic_{partition}_mean.csv` and `results/synthetic_{partition}_std.csv` for the all-, high-, and low-uncertainty partitions. The first seeded run also generates `figures/synthetic_example_2.pdf`.

These files are included so that reviewers can inspect the fitted predictions and numerical results without first waiting for the full run. They are generated from the included input by `python scripts/run_paper.py`; they are not a checkpoint format, and the runner currently recomputes the models rather than resuming from the saved predictions. Recreating every output still takes several hours.

## Outputs and how to reproduce them

Run `python scripts\run_paper.py` to execute `src/hqr_waci/paper.py`, which coordinates the analysis and writes generated files into `results/` and `figures/`. Pre-generated results and figures are included in those directories.
