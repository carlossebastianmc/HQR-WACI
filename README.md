# HQR-WACI

Code and data for the paper:

> Enhancing reliability in prediction intervals using point forecasters: Heteroscedastic Quantile Regression and Width-Adaptive Conformal Inference

## Run

Python 3.13 is required. From the repository root:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python scripts\run_paper.py
```

The run fits the rolling HQR, HQR-W, and QRA models; calculates ACI, WACI, and DCP intervals; runs the synthetic experiment and sigma sensitivity analysis; and writes the paper tables and figures. The complete model fits, 1,000-replicate metric bootstrap, and 2,000-point sigma sweep can take several hours.

Generated tables are written to `results/`. The consolidated `results/paper_metrics.csv` contains one row for each alpha and model, with all nine reported metrics as columns, so the numerical results can be compared directly with the manuscript. Bootstrap samples and standard errors are also saved separately. Generated figures are written to `figures/`.

## Data

`data/df_2024.csv` is the hourly input used by the electricity-price analysis. It contains the observed price and three point forecasts. The script calculates the model features from these columns.

## Project structure

```text
data/          Analysis input
figures/       Figures generated by the run
results/       Prediction and metric tables generated by the run
scripts/       Main analysis runner
src/hqr_waci/  Model, conformal, metric, simulation, and plotting code
```
